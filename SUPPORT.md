# Support

This repository is Brajesh Kumar's GitHub profile repository. It contains the profile page, static images and SVGs, and GitHub Actions that refresh selected profile content. It is not a deployable application and does not provide a hosted API or database.

## Where to ask for help

For a broken local asset, documentation issue, or workflow failure, use the repository's GitHub Issues page if issues are enabled. Include the affected path, the relevant Actions run URL, and what you expected to happen. For general contact, use the public contact methods on the [Brajesh31 GitHub profile](https://github.com/Brajesh31).

Do not put access tokens, private account information, or personal data in an issue. Follow [SECURITY.md](SECURITY.md) for sensitive reports and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.

## Common support topics

- For local Markdown preview and image paths, see [installation](docs/installation.md).
- For the five scheduled or manually triggered workflows, see [deployment](docs/deployment.md).
- For missing images, stale content, or failed Action runs, see [troubleshooting](docs/troubleshooting.md).
- For project scope and external services, see [architecture](docs/architecture.md) and [FAQ](docs/faq.md).

## What support does not cover

There is no application runtime, package installation, model, API service, database, or public uptime commitment in this repository. External badges, feeds, and statistics are operated by their providers, so availability and rendered values may depend on those services.

## Reporting a useful issue

State the file or workflow involved, describe the visible problem, and include safe reproduction steps. Redact secrets and avoid attaching private screenshots or data. For workflow issues, a link to the run is usually more useful than a copied log containing environment details.

## Response expectations

The repository is maintained by Brajesh Kumar (GitHub account brajesh31). Responses are handled as time permits; no response or resolution deadline is promised. Contributions and fixes can be proposed using the process in [CONTRIBUTING.md](CONTRIBUTING.md).
